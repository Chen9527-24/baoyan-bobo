# 宝妍的项目优势

宝妍的主要特点是把儿童陪伴里的接话方式做成可调整、可复用的功能。家长能针对一次不满意的回答提出方向，先看实际变化，再决定它是否适合自己的家庭。聊天记忆也可以查看和纠正。

| 优势 | 可以展示的场景 | 实现入口 |
| --- | --- | --- |
| 儿童接话和情绪承接 | 孩子说「我不想讲学校的事」，观察回应是否尊重意愿，后来主动求助时是否能转到适当建议。 | [人设](../apps/server/src/baoyan-persona.ts)、[对话策略](../apps/server/src/conversation-policy.ts)、[回复计划](../apps/server/src/reply-plan.ts) |
| 回复的表达方式可以调整 | 家长说「先听我说，别马上教我怎么做」，比较回答，确认采用后查看适用条件，并尝试撤回。 | [回答调整界面](../apps/web/src/components/ReplyAdjustment.tsx)、[采用逻辑](../apps/server/src/scene-adoption.ts)、[模拟场景测试](../tests/scene-natural-adoption.test.ts) |
| 关系可以延续，记错可以改 | 用一段虚构聊天表达喜好。观察结束后保存的摘要，再修改同一条记忆或撤回它。后续聊天可在符合条件时自然使用。 | [记忆摘取](../apps/server/src/auto-memory-extractor.ts)、[记忆管理](../apps/web/src/components/MemoryPanel.tsx)、[多日测试](../tests/mobile-memory-quality.test.ts) |
| 声音与角色状态同步 | 同一轮回复拆成短段，角色跟随听、想、说的状态更新。实时语音可以插话，旧回复应停止播放。 | [语音播放分段](../apps/web/src/lib/replySegments.ts)、[状态映射](../apps/web/src/lib/characterMotion.ts)、[实时会话](../apps/server/src/realtime-session.ts) |
| 适合接手和试验 | 先跑规则式文字演示，再用模拟供应商重复固定场景。愿意接入模型的开发者可以用相同输入比较新回复。 | [测试目录](../tests)、[模型接口](../apps/server/src/providers.ts)、[配置样例](../.env.example) |

第一、第二和第三个示例适合成为 README 演示。以当前代码为依据，规则式演示用于看界面和基础流程，带模型的回复、自动摘要和试听需要自有模型配置。自然度应通过同题多轮对话和真机对听来评估。方言路由、声纹适配和设备控制原型可作为技术探索展示，实际效果仍需样本和硬件验证。
