# 宝妍 bobo

宝妍是面向儿童日常陪伴的中文优先语音互动原型。孩子可以用语音、文字或照片开启聊天，家长可以用自己的话调整宝妍的接话方式，也可以查看和纠正聊天记忆。

## 项目特点

| 方向 | 已实现的能力 |
| --- | --- |
| 儿童对话 | 按年龄和情境组织回复。孩子说暂时不想讲时，接话策略会尊重这个意愿。回复可以拆成短段，语气和角色状态随当前对话变化。 |
| 家长可以调整接话 | 对一条回答说出建议，试听或预览新回答，再将认可的做法保存为场景。明确采用后，符合条件的普通聊天可以复用，也支持撤回。 |
| 家庭记忆可以管理 | 区分共享设定和儿童专属信息，专属记忆在适用时优先。家长可以查看、修改、删除或关闭记忆。近期摘要有容量和期限。 |
| 手机语音和图文 | H5 提供普通聊天和独立实时语音。普通聊天支持长按语音、文字和照片。配置实时供应商后，可以连续说话、停顿接话和开口打断。 |
| 可自行运行和验证 | React、TypeScript、Express 与 SQLite。无需模型密钥即可试用本机规则式文字演示，并运行虚构场景和模拟供应商测试。 |

每项能力的代码入口和演示路径见[项目优势与示例](docs/项目优势.md)。

## 本机体验

需要 Node.js 22.13 或更高版本。建议使用 [`.nvmrc`](.nvmrc) 指定的版本。

```sh
npm ci
npm run dev
```

打开 [本机网页](http://127.0.0.1:5173/)，用虚构资料注册本机账号，测试电话可填 `+12025550100`。家庭关联码留空，完成设置后打开文字聊天。发一句“我们的小屋叫什么？”，就能看到预置的虚构背景。数据保存在当前目录的 `.data/`。本机文字演示由规则生成回答。

## 配置模型和语音

所有服务端 API 配置集中在仓库根目录的 `.env`。首次配置时，复制 [`.env.example`](.env.example) 并填写自己要用的能力。公开模板里的凭据字段全部留空。Git 会忽略本机 `.env`。

```sh
cp -n .env.example .env
npm run check:services
```

| 需要的能力 | 填写 `.env` 中对应项目 |
| --- | --- |
| 文字对话、图片理解 | 方舟 `CHAT_API_KEY` 和 `CHAT_MODEL`。识图有单独的模型条件，见模板注释。 |
| 普通语音识别与朗读 | 豆包语音 `VOLC_SPEECH_API_KEY`，朗读再填 `VOLC_TTS_VOICE_ID`。 |
| 实时语音 | 将 `VOLC_REALTIME_ENABLED` 设为 `true`，填写有实时语音权限的 `VOLC_REALTIME_API_KEY`。 |
| 声纹识人 | 显式启用声纹并配置独立凭据和公网 HTTPS 源。普通识别也需配置完整。 |

填好后运行 `npm run check:services`，它只显示本机配置是否齐全。重启 `npm run dev` 后加载新配置。暂时没有 Key 时，可以直接使用前面的本机文字演示。

## 测试和构建

```sh
npm test
npm run build
```

`npm test` 使用合成数据和模拟服务。构建结果分别在 `apps/web/dist` 与 `dist/server`。家长调整与自动记忆的模型效果、真人手机语音及方言质量需要单独验证。

| 路径 | 内容 |

## 当前范围

项目处于原型阶段，本机体验使用虚构资料。普通与实时是独立入口，目前已采用的场景用于普通聊天。实时入口对身份未确认的发言者限制专属记忆读写。儿童多日使用体验、方言准确度和家庭场景中的语音效果仍待验证。

仓库展示宝妍原创封面和静态表情。角色动作切换代码支持配置自备视频素材。
